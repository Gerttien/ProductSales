# ProductsalesQ2

## Question 2 - Product Sales Application

Java GUI application to manage product sales for Microphone, Speakers and Mixing Desk.

### Features
- Load Product Data - shows Total Sales, Average Sales, Sales over limit, Sales under limit
- Save Product Data - saves results to data.txt
- Menu: File > Exit, Tools > Load / Save / Clear
- Years Processed display

### Data Used
- Products: Microphone, Speakers, Mixing Desk
- Year 1: 300, 150, 700
- Year 2: 250, 200, 600
- Sales Limit: 500

### Expected Results
- Total Sales: 2200
- Average Sales: 367
- Sales over limit: 2
- Sales under limit: 4
- Years Processed: 2

### Files
- Main.java
- IProductSales.java
- ProductSales.java
- ProductSalesApp.java
- ProductSalesTest.java

### How to Run
1. Open in IntelliJ IDEA
2. Run Main.java
3. Click Load Product Data
4. Click Save Product Data to create data.txt
